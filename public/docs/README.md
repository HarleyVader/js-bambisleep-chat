# BambiSleep Chat Documentation

Welcome to the BambiSleep Chat documentation system!

## Overview

BambiSleep Chat is a real-time chat application with hypnotic visual effects, text-to-speech capabilities, and trigger word detection.

## Features

### 🎨 Visual Effects

- **Spiral Animations**: Hypnotic spiral patterns with particle effects
- **Trigger Flashing**: Screen flash effects when trigger words are detected
- **Gradient Backgrounds**: Beautiful animated gradients

### 🔊 Audio Features

- **Text-to-Speech**: Automatic voice synthesis for incoming messages
- **Trigger Sounds**: Audio cues when trigger words are mentioned
- **Volume Control**: Adjustable audio settings

### 💬 Chat Features

- **Real-time Messaging**: Instant message delivery via WebSockets
- **Message History**: Persistent chat history
- **User Count**: Live user counter
- **Trigger Detection**: Customizable trigger word highlighting

## Quick Start

1. **Visit the Chat**: Navigate to the main page
2. **Choose Username**: A random username will be assigned
3. **Enable Features**: Use the dropdown controls to enable:
   - Spiral animations
   - Text-to-speech
   - Trigger words
   - AI chat mode

## Controls Overview

### Spiral Control

- Toggle spiral animations on/off
- Adjust speed and intensity
- Control particle effects

### TTS Control

- Enable/disable text-to-speech
- Select voice options
- Adjust speech rate and volume

### Trigger Control

- Enable trigger word detection
- Select which triggers to activate
- Configure flash effects

### AI Control

- Switch between Chat and AI modes
- Configure AI personality
- Set response preferences

## Safety & Usage

⚠️ **Important**: This application contains hypnotic content. Use responsibly and be aware of your mental state.

- Take breaks during extended use
- Be mindful of trigger effects
- Use in a safe, comfortable environment

## Technical Details

Built with modern web technologies:

- **Frontend**: Vanilla JavaScript, p5.js for animations
- **Backend**: Node.js with Express and Socket.io
- **Real-time**: WebSocket connections for instant messaging
- **Audio**: Web Speech API for text-to-speech
