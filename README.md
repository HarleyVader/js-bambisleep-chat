# Bambi Sleep Chat

Modern hypnotic AI experience platform implementing psychological programming principles through cutting-edge AI technologies.

## Tech Stack

- **Frontend**: React with modern hooks and state management
- **Backend**: Express.js with worker threads and MCP integration
- **AI Integration**: LM Studio + Model Context Protocol (MCP) + ElevenLabs Agents
- **Real-time**: Socket.io for synchronous trigger activation
- **Security**: Helmet, CORS, DNS rebinding protection

## Quick Start

1. Install dependencies:

   ```bash
   npm install
   ```

2. Configure environment:

   ```bash
   cp .env.example .env
   # Edit .env with your API keys
   ```

3. Start development servers:

   ```bash
   npm run dev
   ```

## Architecture

- `src/components/` - React UI components
- `src/server/` - Express.js backend
- `src/mcp-servers/` - Custom MCP server implementations
- `src/agents/` - ElevenLabs agent configurations
- `workers/` - Dedicated worker processes
